# Sakshi Jadhav | Digital Marketing Portfolio

A fast, responsive, single-page portfolio built with plain HTML, CSS and JavaScript. No build step needed.

## Deploy on GitHub Pages
1. Create a new repository (for example `sakshi-portfolio`) and upload all files from this folder.
2. Go to **Settings > Pages**.
3. Under **Branch**, choose `main` and `/ (root)`, then Save.
4. Your site goes live at `https://<username>.github.io/sakshi-portfolio/`.

## Customise
- `index.html`: replace the sample campaigns, results, experience, email and social links (search for `sakshi@example.com`).
- `style.css`: change colours in the `:root` block at the top.
